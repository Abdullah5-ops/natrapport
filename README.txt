NATRAPPORT – VERSION 10

Rettet billedfejl: billeder gemmes nu i IndexedDB i stedet for localStorage, så flere billeder kan gemmes uden den tidligere fejl om at billederne fylder for meget.

Billeder komprimeres automatisk til mailvenlig størrelse. Hver kunde kan sendes separat med kun kundens egne billeder. Kundenummer og kundenavn kan forsøges læst automatisk fra kundelabel med OCR og kan altid rettes manuelt. Adressen bruges ikke i rapportteksten.

Efter upload til GitHub Pages: vent et par minutter og genindlæs siden.
