NATRAPPORT – VERSION 3
Åbn index.html i Safari/Chrome. På iPhone kan den installeres via Del -> Føj til hjemmeskærm, når den ligger på en HTTPS-webadresse.
Funktioner: kategorier, kamera, kundelabel, flere varebilleder, flere kunder, lokal lagring, rapportoversigt og deling af mailtekst + billeder via iOS Share Sheet.
Bemærk: Automatisk OCR af kundelabel kræver en OCR-motor/integration; denne version bruger manuel indtastning efter label-foto. En fuld native app kræver iOS-projekt/signering og kan kobles til virksomhedens mail/ERP efter behov.
